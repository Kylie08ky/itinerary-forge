# 票务退票改签与取消政策

> 本资料汇总本知识库覆盖范围内三类票的退改规则：巴黎交通票、巴黎博物馆通票、卢浮宫门票。
> 三类票规则不同，请分别看。细则以各自官方销售条款（CGV / Terms and Conditions）为准。

## 适用人群
〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕

买错票、行程变更、需要退票或改期的游客。

## 核心结论
〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕

- **卢浮宫门票：不能改期、不能改签、不能退款**，仅所选日期时段有效；只有卢浮宫方面取消或变更时才可退。
- **巴黎博物馆通票：可提前数月购买，有效期从第一次使用才开始计算**；是否可退、退多少以官网销售条款为准，一般已激活的不可退。
- **巴黎交通票（单次电子票、日票、周票）：一般不可退不可改**；Navigo Easy 卡不记名，可借给同行人使用。

## 卢浮宫门票退改
〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕

- 门票被视为「休闲服务销售」，**无反悔期（no right to withdrawal）**。
- 门票**只在所选日期和时段有效，不能修改、不能交换、不能退款**。
- 日期和时段一经预订不可更改。
- **例外**：如果卢浮宫方面取消或变更了相关服务，可按官网条款申请退款，退款资格标准见其 Terms and Conditions。
- 官方票务网站：`https://ticket.louvre.fr/en`。

## 巴黎博物馆通票退改
〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕

- 通票可以**提前数月购买**，不激活就不计时。
- **有效期从第一次使用自动激活**，按 48 / 96 / 144 连续小时计算，中途不可暂停。
- 未使用 / 未激活的通票能否退、是否收手续费、办理时限：**以官网销售条款（CGV）和购买渠道规定为准**。已激活的通票通常不可退。
- 通过第三方平台或线下渠道购买的，按该渠道的退改规则处理。
- 只在官方渠道购票，避免仿冒票务网站。

## 巴黎交通票退改
〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕

- 单次电子票（Metro-Train-RER、Bus-Tram）、Navigo 日票 / 周票：**一般不可退款、不可转卖**，买错票或行程取消通常无法退回票款。
- **Navigo Easy 卡不记名**，卡里的票可以借给同行人使用（同一时刻一人一票），因此「买错」时可让同行人使用剩余票值。
- Navigo Easy 卡本身的工本费不退。
- 具体退改与异常处理（如充值失败、设备故障）：以 Île-de-France Mobilités 官网的《General Terms and Conditions of Sale and Use》和官方 App 内说明为准。

## 操作步骤（通用）
〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕

1. 确认你的票属于哪一类、从哪个渠道购买。
2. 找到原购买渠道（官方网站账户 / 官方 App / 线下售票处 / 第三方平台）。
3. 在该渠道查找「退款 / 改签 / 取消」入口；卢浮宫门票无此选项。
4. 按渠道提示提交，留意处理时限和可能的手续费。
5. 涉及官方主动取消或变更的，保留取消通知，按官方条款申请退款。

## 常见问题
〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕

〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕
**Q：我买错票了怎么办？**
- 卢浮宫门票：不能改不能退，只能重新购买正确的票。
- 交通票：若充在 Navigo Easy 卡上，可让同行人用掉；卡不记名。
- 博物馆通票：未激活的按官网销售条款处理。

〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕
**Q：行程取消了，票能退钱吗？**
- 卢浮宫：不能，除非卢浮宫方面取消服务。
- 交通票：一般不能。
- 博物馆通票：未激活的以官网条款为准，已激活不可退。

〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕
**Q：票能转给朋友用吗？**
- Navigo Easy 卡不记名，可借给同行人。
- 卢浮宫门票、博物馆通票是否可转让以官方条款为准，一般绑定购买人信息。

## 注意事项
〔来源：《票务退票改签与取消政策》· louvre.fr / parismuseumpass.fr / iledefrance-mobilites.fr〕

- 三类票退改规则差异大，不要用一类的经验套另一类。
- 具体金额、时限、手续费本资料不写死，一律以对应官方销售条款为准。
- 通过第三方平台购票的，退改走平台规则，可能比官方更严格。
