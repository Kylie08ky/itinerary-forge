# M15 移动端与离线

> 版本：v0.2（响应式、PWA、离线只读，已提前）→ v0.3 批次 F（今日视图、手机底栏的「今天」，已提前）→ v1.0（离线编辑、离线瓦片）
> 功能：F90 F91 F92 F93 F94 · 来源：TREK（PWA、离线）

## 为什么

出国时主要用手机看行程，网络可能不稳定。要保证：**手机上好用，没网也能看到今天的安排**。

## 范围

做：移动端布局（底栏，F91）、可安装的 PWA（F90）、离线查看已打开过的行程（只读，F92）、今日视图。
后做（v1.0）：离线编辑 + 幂等重放（F93）、离线地图瓦片（F94）——同步冲突复杂，先不承诺。

## 验收场景

**S1 P0 · 手机宽度可用（v0.2 已做）**
- 假设 视口 375px
- 那么 无横向滚动；时间轴、地图、预约清单都可操作；按钮、下拉框、地图缩放按钮的点击区域 ≥ 44px
- 覆盖页面：首页（含候选池）、我的行程、行程页（含分享面板、全程地图、生成过程、编辑模式）、公开分享页、模型用量
- 注：手机上没有拖拽（HTML5 拖拽不支持触屏），编辑靠每个地点下面的「移到…」「换一个」「锁定」「删除」
- 并且 手机上行程时间轴每一条是：圆点在左、时间在上、内容占满剩下的宽度（≥ 220px）；以前三块被塞进两列，内容会被挤成一条窄列（v0.3 批次 G 验收时发现并修好，浏览器验收里加了内容列宽度的检查）

**S2 P1 · 今日视图（v0.3 批次 F）**
- **S2a 今天在不在行程里**：用**目的地的时区**（巴黎 = Europe/Paris，含夏令时，由浏览器算，不依赖你手机 / 电脑的时区设置）判断今天是几号、现在几点；今天落在某份**未归档**行程的日期范围内就算「行程进行中」。几份行程重叠时取最近创建的。
- **S2b 「今天」卡片**（首页最上面、行程页封面下面各一张，同一个组件）：标题「今天 · 第 N 天 / 共 M 天 · 日期（周几）」；然后按现在的时间显示——
  - **正在进行**：「现在：橘园美术馆（到 12:00 结束，还有 25 分钟）」；
  - **下一站**：名称、开始时间、「还有 N 分钟 / N 小时 M 分」、地点、**「🧭 导航」按钮**（Google 地图，**起点 = 你当前位置**，终点 = 核对过的坐标，公共交通；没有坐标的安排不给导航）；**下一站是午餐 / 晚餐这类餐饮占位（没有坐标）时，改给「🍽 搜附近餐厅 ↗」**（Google 地图搜索，范围是你当前位置附近）；**正在进行的是午餐 / 晚餐时（比如你正在吃晚饭）也一样给「🍽 搜附近餐厅 ↗」**；下面小时间轴里**每一条有坐标的安排右边都有一个「🧭 导航」链接**（含已结束的），没有坐标的餐饮安排（还没结束的）右边是「🍽 附近餐厅」，所以不管现在几点、下一站是什么，都能点到导航；
  - **还没开始第一项**：「今天第一站：xx，HH:MM 开始」；**今天全部结束**：「今天的安排都完成了」并预告明天第一站（最后一天不预告）；
  - 下面是今天全部安排的小时间轴：已结束的划线变灰、正在进行的高亮、还没到的正常；每 30 秒自动刷新状态，不用手动刷新页面。
- **S2c 不显示的情况**：今天在行程第一天之前（首页照旧显示「下一站」倒计时）、在最后一天之后、行程已归档——都不出现「今天」卡片和底栏的「今天」。
- **S2d 手机底栏多一个「今天」**：行程进行中，底部标签栏变成 4 项（新建 / 我的行程 / **今天** / 用量），「今天」点进 `/today`——一整页的今日视图（同样的卡片，字更大，下面接着是今天各安排的备注和导航）；不在行程中底栏和以前一样 3 项。桌面顶部导航条不加。`/today` 在没有进行中的行程时显示「今天不在任何行程里」并给「我的行程」链接。
- **S2e 离线也能看**：全部用已缓存的行程和地点库在浏览器里算（后端没有新接口），所以先联网打开过行程，出门没网也能看到「今天」；离线时导航按钮照常（它只是一个 Google 地图链接，点开后需要联网）。
- **S2f 行程页里今天那一天**：行程页的目录条多一个「今天」入口（行程进行中才有），当天的标题行有「今天」小标记。

**S3 P1 · 可安装（v0.2 已做）**
- 假设 我在手机浏览器点「添加到主屏幕」（或桌面 Chrome / Edge 地址栏的「安装」）
- 那么 以独立窗口打开（standalone），名称「旅行规划」、图标是橙底白色定位针；打开直接进「我的行程」
- 实现：`manifest.webmanifest` + 图标（192 / 512 / 可遮罩 512 / apple-touch）+ Service Worker；浏览器的可安装性检查（CDP `getInstallabilityErrors`）为空
- 注：Service Worker 只在生产构建里注册（开发服务器上它会缓存旧代码）

**S4 P1 · 离线只读（v0.2 已做）**
- 假设 我先联网打开了行程，然后开启飞行模式
- 那么 重新打开仍能看到行程、预约清单、全程地图（看过的地图瓦片还在，没看过的缺图）；页面顶部显示「离线 · 只读」，并说明地图底图可能不完整
- 并且 离线时：没有「编辑行程」、「分享」置灰、一句话修改和「回滚」不出现、首页「生成行程」置灰并说明原因；「我的行程」列表也能看
- 并且 没联网打开过的行程，离线时显示「连不上后端」的错误提示，而不是白屏
- 并且 联网后刷新，提示消失、编辑 / 分享恢复
- 缓存策略：页面外壳和构建产物首次联网时预缓存；后端只读接口（行程、路线、地点、主题、分享…）先走网络、断网退回缓存；地图瓦片最多留 400 张；写操作、导出下载（PDF / ICS / KML）、任务进度、模型用量一律不缓存
- 判断「离线」不只看 `navigator.onLine`：请求发不出去、或响应是缓存顶上的（响应头 `x-from-cache`），也进入只读

- **自动化**：`tests/e2e/test_v03_today.py`（用浏览器的假时钟把「现在」拨到各种时刻：行程前 / 第一项前 / 进行中 / 间隙 / 全部结束 / 最后一天之后 / 夏令时切换日 / 归档 / 底栏 3 项与 4 项 / 手机宽度无横向滚动 / 点击区域 ≥ 44px / 离线读缓存）；`tests/e2e/test_v02_mobile.py`（375px：横向溢出 + 点击区域 ≥ 44px，逐页）；`tests/e2e/test_v02_pwa.py`（manifest、图标、可安装性、离线读行程、写操作不缓存）。
- **前端**：你用真机按 S1–S4 看。
