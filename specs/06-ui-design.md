> **方向修订 3（2026-10-22，你看了 Wandor 和 Mostar 两个参考页之后）**：**首页用 Wandor 的结构**——全屏实拍背景 + 大标题 + 一张毛玻璃提示卡；**行程页封面用 Mostar 的结构**——全屏滚动舞台，标题上浮、照片拉近变模糊、统计面板和「行程亮点」卡片依次出现（紧凑版，约 1.5 屏）。你已拍板：

> - **首页提示卡**：自然语言填表（M01 S10–S13）——写一句话，本地模型读懂意图、把日期 / 天数 / 主题 / 人数 / 预算 / 想去的地点填进下面的表单，**你确认后才生成**；排程仍由算法做。

> - 这一版**修订了下面的设计原则 6**：封面现在可以用实拍大图（仍然不依赖图片：没有就退回渐变）；PDF、长图仍不放图。

> **方向修订 2（你看了手册风 + 觉得「和人家的作品太雷同」之后）**：不再用「森林绿 + 奶油米白 + 衣线斜体数字 + 悬浮胶囊标签栏」这套和参考作品一模一样的组合。
> 新方向 = **TREK 式紧凑仪表盘（结构：细导航、圆角矩形、1px 线、统计小卡片、左日程右地图）+ 手册式大封面 / 大标题**，**颜色由目的地城市决定**。
> - 巴黎（目前唯一的城市）：奥斯曼建筑的石灰岩米白做底，锌皮屋顶的蓝灰做主色，黄铜（窗栏 / 路牌）做点缀；封面是锌皮屋顶的竖向接缝纹理 + 底部一条黄铜细线。
> - 和参考作品刻意拉开的地方：没有绿色；标题衣线体用**直体**（不用斜体）、数字用等宽数字；按钮是圆角矩形而不是胶囊；手机底栏是**通栏 + 选中项顶部黄铜条**，不是悬浮胶囊；倒计时是「登机牌」式四格而不是大号斜体数字。
> 你拍板：封面先用渐变 + 纹理（景点照片等批次 G）；衣线字体用系统字体；这一轮改行程页、首页表单、我的行程列表，分享页和 PDF 后续再跟。

## 城市配色
- 每个目的地一组颜色，来自这座城市自己的材质；写在 `web/src/cities.css` 的 `:root[data-city="xxx"]`（浅色 + 深色各一块）。新增城市 = 加一块配色 + 在 `web/src/themes.ts` 的 `CITY_KEYS` 里登记，**不改组件**。
- 组件只用变量：`--bg / --surface / --ink / --accent / --warm / --brass / --cover-a / --cover-b / --cover-ink`；没有专属配色的城市退回 `theme.css` 里的中性石墨色。
- 行程页按行程的目的地切换配色；首页 / 列表 / 用量页用默认城市（巴黎）。

## 设计原则
1. **像一本能随身带的手册**：留白大、层次清楚、一屏一件事；标题有杂志感，信息卡片干净。
2. **颜色克制、跟城市走**：城市主色做按钮 / 选中态 / 封面，黄铜只给小标签和细线，状态色（绿 / 橙 / 红）只在提示时出现。
3. **衣线 + 黑体搭配**：只有大标题、大日期、倒计时数字用衣线（直体）；正文、统计、表单用黑体，数字等宽。
4. **日程和地图并排**（桌面端）：左边读日程，右边固定的大地图；手机上地图折叠，底部是通栏标签栏。
5. **每一天有自己的颜色**：「第 N 天」徽标和全程地图上那一天的线同色（沿用）。
6. **封面不依赖图片**：封面可以用一张实拍大图（修订 3：首页背景、行程页封面舞台），但**没有图 / 加载失败时必须退回**城市主色渐变 + 接缝纹理 + 淡淡的主题大图标，页面照样完整。v0.3 批次 G 起，**地点详情卡、时间轴缩略图、地图气泡**用 Wikimedia 授权实拍图（带署名，M02 S7b）；封面、PDF、长图仍不放图；分享页也有缩略图和照片。
7. **深色主题同样精致**（深蓝黑底，不是纯黑）。
8. **手机可用**：375px 无横向滚动，点击区域 ≥ 44px；底部标签栏不遮住内容。
9. **少写次要说明，让布局自己讲**（你 2026-10-27 加进 AGENTS.md）：不写没必要的次要标签和描述。标题、分组、位置和默认值能说明的，不再加一句解释；选填是默认，不逐项标「（选填）」，只标必填；示例放进输入框的占位文字，不放进标签；空状态只留标题和按钮。**该留的**：改变结果的信息（单位、必填、隐私承诺、来源链接）和出错提示。10 月 27 日按这条梳理了新建页（页首说明、每一步的说明段、「选填」括号、日期括号、候选池说明）、深度路线卡（去掉两行说明，主线移进展开后）、「这趟旅行里的作品」和作品参考页、我的行程空状态、周边一日游的小字。

## 视觉规范
圆角：卡片 18px、内层 12px、控件 10px、小标签 8px / 药丸；阴影极轻，以 1px 线为主；标题字体 `Georgia, "Songti SC", "Noto Serif CJK SC", "Source Han Serif SC"`（Windows 上中文落到加粗黑体）。颜色见上面「城市配色」。

## 页面
**全局导航**：桌面端顶部一条细导航（品牌 + 新建行程 / 我的行程 / 模型用量，当前页浅蓝底 + 黄铜下划线高亮）；**手机端**顶部只留品牌，导航换成**底部通栏标签栏**（新建 / 我的行程 / 用量，当前项主色 + 顶部黄铜条）。公开分享页不显示。

**首页（修订 3：Wandor 结构）**：见 S11–S14。首屏是全屏实拍背景（巴黎地标大图 + 缓慢的镜头推进）、大标题「你想去哪里？」、一句话说明和一张毛玻璃提示卡；表单三张卡片仍在首屏下面。下面保留的是旧版说明（顶部导航、倒计时卡、表单分三张卡片不变）。
- （旧）大封面横幅：衣线大标题 + 一句话说明 + 淡淡的主题大图标。
- 如果有即将出发的行程：横幅下叠一张「**下一站，巴黎**」卡片——距离出发的天 / 时 / 分 / 秒倒计时（每秒走）+ 「查看行程」。
- 表单分三张编号卡片（①选主题 ②行程信息 ③偏好）；主题是带图标的圆角卡片，选中主色描边 + 对勾；底部固定的「已选主题 · 共 N 天 · 生成行程」栏（手机上在标签栏上面）。

**我的行程**：封面卡片网格（城市色封面 + 淡图标 + 天数徽标），标题衣线体，状态胶囊；归档 / 删除在卡片底部。

**行程页封面（修订 3：Mostar 结构，紧凑版）**：见 S15–S20。进入行程页先看到一个全屏封面舞台，滚完约 1.5 屏后接上原来的页面（统计小卡片、操作栏、目录条、每天日程）。
**行程页**
- （旧）封面卡：衣线大标题、**大号衣线日期「10.20—10.23」** + 「共 4 天 3 晚」、主题 / 节奏 / 预算胶囊；其下四个统计小卡片。
- 主操作：「编辑行程」（主色实心按钮）「分享」「下载 PDF」，其余在「更多」菜单。
- 桌面端右侧固定全程地图；窄屏折叠。每一天：彩色徽标 + 日期 + 主题，**右侧是这一天的天气**（M10 S1a）；住宿提示用暖色小标签。
- **每一天可以展开 / 收起**：点这一行（或右侧小箭头）收起，只剩标题行 + 天气 + 「N 个地点」；日程上方有「全部展开 / 全部收起」。默认全部展开；**记住上次的收起状态**（存在这台浏览器里，每份行程 / 每个分享链接各记各的；浏览器不让存时退回默认全部展开）。编辑时收起的天仍然可以作为拖拽的落点。

**行程页减负（Q4，规格 07 P10–P14）**
- **顶部只留结论**：标题、日期、统计、操作按钮、版本切换。质检结果、「生成过程（耗时与模型调用）」、模板说明、「日期平移后…」这类说明**不再出现在顶部**，统一在「更多 → 生成详情」弹窗里；质检没问题时页面上完全看不到「质检」；有错误 / 警告时顶部出现一条「有 N 条提醒」（点开是人话的提醒列表）。
- **说明收起来**：预算每一项只显示名称、金额、来源小标记（人均、待补照常显示），计算依据收进「ⓘ 计算依据」；每个地点默认只显示：时间、名称 + 缩略图、一行副信息、一行关键徽标（来自笔记 / 必须提前线上购票 / 官网购票 / 雨天），名字旁边有一个「详情 ›」小标签，点它打开地点详情浮窗（地址、交通、票价、闭馆日、参观重点、购票说明、核对记录都在浮窗里，条目里不再行内展开）；「备注」入口变成一个不抢眼的小字按钮。

- **地点详情浮窗分块排版**：顶部是名称 + 英文名 · 类别 · 区 + 购票徽标（必须提前线上购票 / 官网购票）；然后依次是 简介、「基本信息」（地址 / 交通 / 建议停留 / 票价 / 闭馆日，带分隔线）、「购票说明」、「参观重点」（清单，不是一堆标签）、「小贴士」、「属于主题」（只写主题和主要点 / 辅助点，权重放在悬停提示里）；坐标 / 闭馆日 / 官网链接的核对记录收进「数据核对记录」，默认收起。

**行程页的「本页目录」（页面太长，找不到某一栏）**
- **宽屏（≥ 1280px，Q4 起）目录是页面最左侧的一列竖栏**（文字列表、当前栏目浅色底 + 左侧色条高亮，滚动时固定、条目多时自己可滚，点一项滚到那一栏）；中间是日程，右侧仍是固定的大地图。窄屏和手机仍是顶部吸附的横向目录条。栏目顺序（Q4 起）：`概览 · 第 1 天 … 第 N 天 · 购票与风险 · 住宿 · 预算 · 随行 · 修改意见 · 版本历史`（随行清单、预算、住宿都在日程之后），只列出这一页**实际有**的栏目（编辑中 / 对比版本时没有的栏目不列）。
- 点一项平滑滚到那一栏，停在目录条下面不被遮住；点某一天时，如果这一天是收起的，**自动展开**。
- 滚动时当前所在的栏目高亮（滚动监听）；条目多时横向滚动，当前项自动滚进可见范围。手机上同样吸附在顶部，点击区域 ≥ 44px。

## 深度路线、文化、美食与当季活动的界面（2026-10-26 至 10-28）

**新建页的「深度路线」**（和主题二选一，按兴趣线分组：历史 / 民俗体验 / 美食 / 其他，没有路线的组不显示）
- 每条路线一张卡：名称 + 一句话 + 「推荐最少 N 天 · 建议 N 天 · 几章 · 几站」+ 几个站名；主线、每章的站和为什么在这条线上、延伸阅读收在「看看这条路线讲什么」里。
- **限定路线**（路线上每一站都是当季活动，如「巴黎的圣诞集市」）：标题旁有「限定」小标签，卡片里写出举办期（「2026 年 11 月 26 日 – 12 月 27 日」）；你选的日期和举办期没有重合时，卡片下面出现一行提示「当前日期没有这个活动：举办期是……」（只提示，不拦你选）。
- 选了路线后每一站前面有勾选框（默认全选），有「全选」「只留核心站」；日期少于推荐天数、多于路线内容时各有一行提示。

**路线行程页**
- 按章往下走的路线：每天顶部是「第 N 章 · 标题」小标题 + 一段导览；导览是**左边一道细线、正文略小**的轻量样式（不是灰色大块）；每个景点下面一行「为什么在这里」、一行「看什么」；底部是路线卡片（主线、延伸阅读、策展说明）。
- 「每天每类挑一家」的路线：一天顶部**没有**章标题和导览，一天的标题就是这天去的几家；说明全在每一站自己下面。
- 偏离路线时顶部提示；封面把路线上排进来的站都放出来。

**作品、招牌与当季活动**
- 行程条目下面：最多 2 条「这里的故事」（电影《午夜巴黎》：……）或「招牌：马卡龙」（招牌排在作品前面），多的提示「还有 N 条，点『详情』查看」；地点卡里列全部，带来源链接；没有故事 / 招牌的地点不出现空块。
- 当季活动的地点卡上有「当季活动 起 至 止」标签；日期没能在官网核对的写明「出发前请确认」。
- **「了解巴黎」参考页**（`/culture`，没有导航入口，从行程页「这趟旅行里的作品」点「更多」进）：作品按类型分标签（全部 / 电影 / 纪录片 / 书 / 播客，没有的类型不出现）+ 「美食」标签（名菜名点）。

## 界面优化（2026-11-04，场景 S24–S27）
参考 Google / Apple 的输入框与卡片层级、Dribbble / Behance 的旅行类稿子。第一批（S24–S27）：首页、我的行程、手机行程页；第二批（S28–S30）：新建行程、行程页桌面版、用量 / 版本足迹。配色仍是巴黎的锌皮蓝灰 + 黄铜 + 石灰岩米白，不加新色；不放表情符号，图标用线性 SVG；点击区域 ≥ 44px；不加说明性小字，让版式自己说话。
- **S24 首页**：输入卡下面一排**示例短句**（4 条，点一下把整句填进输入框，不自动提交，`data-testid="nl-suggest"`）；有下一站时，英雄区里有一张**登机牌式「下一站」**（城市衣线大字 + 天 / 小时 / 分 / 秒，虚线分隔，右侧箭头进行程；桌面在右下，手机在示例短句下面；`data-testid="next-trip"` 不变，数字照旧每秒走）；没有行程时英雄区里没有它。「开始规划」按钮是黄铜色，空的时候灰着。首页其余（署名、导入笔记、`nl-*` 的 testid、即将出发、去哪座城市）不变。
- **S25 我的行程**：页头是衣线大标题 + 搜索框 + 范围切换（「进行中 (N)」「已归档 (N)」，**始终显示**）+「新建」；封面卡更大：封面里直接是**城市大字 + 日期**，左上角状态胶囊（还有 N 天 / 明天出发 / 进行中 · 第 N 天 / 已结束 N 天前），封面底部一条黄铜线；封面下面是天数、主题等小标签，卡片底部「归档 / 删除」。即将到来的**第一张卡在宽屏占两列**。搜索框按标题或日期过滤（含正在显示的那一组），没有结果时写「没有匹配的行程」。「即将到来 / 已结束」分组、已结束默认只展开最近 6 条、`group-*` 与 `plan-card` 的 testid 不变。
- **S26 手机行程页**（≤ 720px）：不改封面舞台的降级（S17）；封面之后：① 本页目录条吸附在顶部，当天高亮成**实心胶囊**（≥ 44px，横向滑动）；② 全程地图在手机上**默认展开**成通栏地图（左右不留边、上下圆角，高约 220px）；③ 每个地点是**圆形序号 + 竖线**串起的时间轴，点击区域 ≥ 44px，地点之间的步行 / 交通是一行小胶囊；④ 一天的警告横幅（如「须提前预约」）用暖黄横条。无横向滚动。（可拖动的底部抽屉 + 地图在上的结构这一轮不做，见进度总览。）
