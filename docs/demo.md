# 演示脚本（约 7 分钟）

一条线讲清楚：**写一句话 → 得到一份可核对、可修改、可带走的行程**，以及为什么它比「让模型直接写行程」更可靠。每一步写了「怎么点」「讲什么」「预期看到什么」。

## 演示前

1. 启动：后端 `python -m uvicorn app.api:app --port 8137`，前端 `cd web && npm run dev`，打开 http://localhost:5173（Docker 见 [自托管](self-hosting.md)）。
2. 想展示模型写的说明就开着 Ollama；不开也行，说明会用模板，演示照常（还能顺便讲「模型挂了也能出行程」）。
3. 提前生成好两份行程当备用（现场生成一份约 1–3 分钟）：巴黎艺术 + 美食 4 天，和「艺术：从王室收藏到当代」这条路线 3 天。
4. 没有现场环境时，截图在 [`images/`](images/)，用 `python scripts/capture_screenshots.py` 可以重新生成。

## 流程

| 时间 | 怎么点 | 讲什么 | 预期看到 |
|---|---|---|---|
| 0:00 首页 | 在输入框写「12 月 6 号去巴黎玩 4 天，两个人，喜欢艺术和咖啡馆，预算 700 欧，想去奥赛博物馆」，点「开始规划」 | 用户只用自然语言。日期、天数、人数、预算这些由**规则**读，模型只补「喜欢什么」，且只能落在固定字段里 | 跳到新建页，表单已填好，顶部写「我是这样理解的」；没有自动生成，由你确认 |
| 0:45 新建页 | 看主题区和「深度路线」；点开「艺术：从王室收藏到当代」看章节 | 两种入口：主题（地点池 + 权重）和深度路线（有章节顺序的故事）。默认「均衡」：我不知道去哪，请直接推荐 | 路线卡有建议天数、章数、站数；展开能看到每章每一站 |
| 1:15 生成 | 点「生成行程」 | 进度是真实的步骤，不是假动画；可以离开，回「我的行程」找得回 | 读取地点库 → 选点排程 → 质检 → 写说明，逐步亮起 |
| 2:00 行程页 | 看封面，往下滚到第 1 天 | **分天、顺序、开放时间、闭馆日、午饭全是算法**，同样输入每次同样结果；模型只写说明，写完逐条检查，不合格整段换成模板 | 每天上午 1、下午 1、晚上 1 加午饭；左侧目录、右侧全程地图，点位按天分色 |
| 2:45 可信度 | 点某个地点的「详情 ›」 | 官网链接、闭馆日、价格只来自带核对记录的数据，**永远不信模型给的网址**；核对不了的写「以官网为准」 | 浮窗里有照片署名、闭馆日、购票说明、官网核对日期 |
| 3:30 文化织进行程 | 在艺术行程里找有「电影《…》：拍摄地点之一」的条目 | 系统替你做功课：故事挂在地点上，不用先看作品再选 | 条目下出现「这里的故事」；页面下方「作品」汇总这趟走过的作品 |
| 4:00 修改 | 点「编辑行程」：把某个地点拖到另一天；对某个地点点「换一个」，选「换成它」 | 改完立即重排并重新质检；每次保存是一个版本 | 当天顺序重算，没有闭馆冲突；页面底部「版本历史」多一条 |
| 4:45 回滚 | 在「版本历史」点 v1 的「回滚到这版」 | 随便改，随时回得去 | 行程回到最初的样子 |
| 5:15 交付 | 点「下载 PDF」；点「分享」再点「生成分享链接」 | 带走的方式：PDF、日历（ICS）、地图文件（KML）、长图、只读分享链接 | PDF 有封面统计和全程路线图；分享页不含姓名、年龄 |
| 6:00 手机 | 浏览器切到手机宽度（375px）打开同一份行程 | 手机可用，底部有地图抽屉，可添加到主屏幕、离线只读 | 底部「地图」按钮打开抽屉 |
| 6:30 收尾 | 打开 [评测报告](evaluation.md) | 质量怎么保证：排程 20 份固定请求硬约束违例 0；事实的核对覆盖率有数字；诚实写了没覆盖的 | 报告里的数字由脚本现算 |

## 可以追加的亮点（按观众兴趣选）

- **任意目的地**：新建页写一座库里没有的城市，后台自动现建（几分钟），行程里明确写「数据是自动建的，价格和预约以官网为准」。
- **多城市**：写「圣诞去意大利，罗马、佛罗伦萨」，得到一份行程、每天标城市，换城市那天按火车 / 机场写。
- **国内**：配了高德 Key 后，国内行程用高德地图，库外地点能在高德里搜，点一下才查真实通勤时间。
- **周边一日游**：从你的住址出发，按时间和交通方式排序目的地，「排一天」。
- **笔记导入**：粘贴朋友的笔记，自动找出地点并标出处；库外地点进「待核实」，不排进行程。

## 被问到时

- **为什么不直接让大模型写？** 开放时间、闭馆日、价格、网址模型会编。这里这些事实只来自核对过的数据，排程是确定性算法，模型只负责理解和表达，输出还要被检查。
- **本地小模型质量够吗？** 说明偶尔不合格，会被丢掉换成模板，所以不影响行程是否正确；7b 和 14b 的对比见 [model-eval](model-eval.md)。
- **数据覆盖哪些城市？** 巴黎完整精校；意大利十座城市补核了一部分；其余自动现建。覆盖率见 [评测报告](evaluation.md)。
- **能多人协作吗？** 暂时不能：没有账号和协作，是自己和朋友用的形态。
